# 📊 Mutual Fund Portfolio Tracker

A modern React-based web application that helps users track and analyze their mutual fund investments in a clean dashboard.

---

## 🚀 Live Demo
👉 https://mutual-fund-frontend-project.vercel.app

---

## 🛠️ Tech Stack
- React.js
- JavaScript (ES6)
- CSS3
- HTML5

---

## ✨ Features
- 📈 Portfolio overview dashboard
- 📊 Asset distribution (Equity, Debt, Gold)
- 💰 Investment tracking UI
- ⚡ Responsive design
- 📉 Data visualization using charts
